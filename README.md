# ForgeBoard

**A modern full-stack issue tracking and project management application built with React, TypeScript, and ASP.NET Core.**

> 🚧 **Status: Active Development** — ForgeBoard is an ongoing personal project focused on modernizing an earlier ASP.NET MVC BugTracker application.

## Overview

ForgeBoard is a modernization of my original BugTracker project, which was built using ASP.NET MVC.

The goal is to revisit the original application's concepts and rebuild them using a modern full-stack architecture, incorporating the practices and experience I've gained through professional software development.

Rather than simply upgrading the original codebase, ForgeBoard is an opportunity to rethink application structure, API design, frontend state management, and maintainability.

The project is organized into two applications:

- **forgeboard-ui** — React and TypeScript frontend
- **forgeboard.api** — ASP.NET Core Web API using .NET 8 Minimal APIs

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, TypeScript |
| Backend | C#, ASP.NET Core, .NET 8 Minimal APIs |
| Architecture | Separate frontend and REST API |
| Version Control | Git, GitHub |

## Project Goals

ForgeBoard is being developed with several engineering goals in mind:

- **Modernize an existing application:** Revisit the original BugTracker's design and functionality using current technologies.
- **Separate frontend and backend concerns:** Build a standalone React application communicating with an ASP.NET Core API.
- **Improve maintainability:** Organize code around clear responsibilities and reusable components.
- **Develop practical API architecture:** Apply modern backend patterns for routing, validation, data access, and error handling.
- **Build incrementally:** Prioritize a functional, maintainable application while iterating on features and architecture.

## Development Status

ForgeBoard is currently under active development. Features, application structure, and implementation details may change as the project evolves.

## Background

The original BugTracker was one of my earlier full-stack development projects.

Since building it, I've gained more than four years of professional experience developing and maintaining production applications using C#/.NET, React, SQL, and related technologies.

ForgeBoard represents an opportunity to apply that experience to an earlier project, approaching familiar problems with a stronger emphasis on architecture, code quality, and long-term maintainability.
